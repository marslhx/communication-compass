## 1. 传播学在中国大陆的再引进与学科化

### 可保留

- 地理范围明确为中国大陆，且提醒 1978 年不是中国传播思想或传播研究的“零年”，避免把现代学科建制与全部传播史混为一谈。
- `current_evidence_state` 和局限栏承认未取得 1982 年会议原始纪要；没有补写具体参会人或地点。
- 1997 年建制变化与教育扩展的叙述有 C17、N-CN-02 线索，且未把 2019 年统计外推为当前数量。

### 必修项

1. **会议称名与引语需保留来源层次。** 第 40 行把“1982 年第一次全国传播学座谈会提出……”直接写为无归属事实，而短名单明确将正式会名和文件原文列为待核。已有 C16/C17 两项后出材料可以支持“后出学术史如此记述”，不能因此写成已核会议原件。最小修改：“据 C16、C17 的学术史记述，1982 年的一次全国传播学座谈会提出了……；会议正式名称与原始记录待核。”若继续使用精确称名和十六字原文，应在同一可见主张内注明“后出记述”，不要只藏于折叠局限栏。
2. **`direct` 不等于一手档案。** 该项改写为“C17 记述……”后可为 `direct`；若继续断言原始会议事实，必须保留后出材料性质和待原始记录复核说明。C17 的官方托管地址与登记中的 `A-primary` 不会使后出的学科史文章成为会议一手资料。
3. **作者与编辑判断需归属。** 第 32 行“再引进是必要限定”、第 64 行“了解—研究—吸收—创造”的递进结构属于解释性组织。建议改成“本节点采用‘再引进’以强调……”并设 `interpretive`。第 64 行“至今”超出 2019 年文献的时间范围，应改为“所引 2019 年综述将……视为仍需推进的问题”，或补新证据后再谈当前状态。
4. **摘要开头的历史链条不是完整因果链。** “并经1982年……逐步学科化”可误读为一条已证实的单线进程。改为“以译介、座谈会、课程教材与学科建制等线索观察其发展”，保留不同材料各自支持的节点，不增加未经核实的因果关系。
5. **争议边界。** “最低共识”需要跨文献审查才能成立，建议改为“当前来源共同覆盖的有限叙述”。冷战语境若只在编辑导航理由中出现，应注明是拟探索的问题，不把未定位的背景直接称为已有明确争论。

### 关系、定位与时效

- `r1-china-introduction → builds_on → r1-process`：**hold**。N-CN-02 记录信息、传播、受众、效果等知识经译介，不能充分证明“学科史研究主题”承接一个由本项目编制的“传播过程与基本要素”概念节点。改为已有 `learning_links` 足够，无需为保留连线改造证据。
- 与 `r5-china-history` 的 `contrasts_with`：比较对象与时间尺度明确，可作为 **interpretive** 候选；另一节点中保存了逆向同义边，合并时只保留一条。
- “正文有关……的段落”仅是内容提示，建议补段落首句或稳定小标题；N-CN-01 标注摘要符合其访问范围。
- `evolving` 的三个时效字段齐备；2026-09-11 是草案作者记录的核验日，本审查没有独立重核其外部材料。

## 2. 马克思主义新闻观

### 可保留

- `type: tradition` 与 `naming_boundary` 合理：明示它不是单一作者一次提出的封闭理论，不等于所有媒体的实际表现。**没有误写成单一经验理论。**
- 对教材规范、陆定一文本的学术解释、案例教学事实作了区分；“规范要求不能证明实践已经实现”的提醒应保留。

### 必修项

1. 第 187 行“现行中国高校教学体系……”主要凭 2019 年教材 C19，范围过宽且带当前有效性承诺。最小修改：“2019 年《马克思主义新闻观十二讲》以……组织教学内容。”若需判断现行全国高校课程体系，应使用对应时期的政策或课程证据，不能以教材目录替代。
2. N-CN-03 是 2020 年作者对 1943 年文本的研究。最小修改为“朱至刚（2020）将该文的理论结构理解为……”，将这一解释列为 `direct`（直接报告作者观点）或 `interpretive`（编辑综合），不能把它当作陆定一原文已亲核。确切版次与原载位置目前来自参考文献，保留来源链；原始报纸正文为待核项。
3. 第 207 行把“真实性”与“党性、人民性”等并列为规范主题可以成立，但局限栏不宜把“真实性”在所有研究中的性质都说成首先是规范命题。应限为“在本节点所引教材和规范框架中，这些表述作为应然要求呈现”。同一术语还可能成为经验研究的分析对象，现有材料不能统一裁定它在全部传播研究中的性质。
4. 第 215 行的课程事实应锁定 C13 所述课程、年份和组织范围，避免“全国性案例课程”被理解为全国所有高校的常态。C18 的登记为搜索摘要已核、正文访问异常，适合辅助证明案例教材出版线索；不得以“教育部页面出版说明”的 locator 暗示本轮已看到全文。
5. `internal_differences` 实际上列的是材料层级差异，尚非同一传统中不同观点的展示。可以保留材料分层提示，但改名需经本体决定；若仍放此字段，转成带证据的 claim，并明确这是“历史与材料层次”，不要声称已完成内部思想分歧呈现。

### 关系、定位与时效

- `tradition → addresses → r5-journalism` 的端点类型合规；按“教材讨论新闻学哪些问题”收窄并补 `scope_note` 后可保留，不能显示为这些回答已经经验验证。
- 指向 `r5-political` 的 `addresses` 端点合规，但“党—政府—人民关系”的完整命题并未由现有目录定位说明充分支撑。删去超出目录的概括、限定“新闻传播的政治维度”，并降为 **interpretive**；若坚持宽泛领域覆盖，**hold** 至取得匹配正文。
- 四个相对稳定节点之一，缺 `last_evidence_check`。若正文保留“现行”与具体课程状态，另需明确 `as_of`/定期复核或移除当前性承诺。

## 3. 中国新闻传播史

### 可保留

- 明示是跨时期导览，并区分教材课程范围与具体历史事件原始证据；没有把一本通史当作最终历史。
- 首条明确包含 1949 年以来台港澳新闻事业，**不存在完全用大陆史替代台港澳史的写法**。
- 方法、史料与史学框架被纳入学习价值；把争议限定到分期、边界和范式，未说全部史实都可任意争论。

### 必修项

1. **覆盖仍不完整，必须明示。** 当前首版骨架几乎完全沿 C15 目录；未说明少数民族新闻传播、跨国华文传播，以及台港澳更早时段的覆盖情况。C12 登记显示少数民族与海外华文研究分支，只能证明存在相关研究领域，不能补出各地历史事实。最小补充：“当前样本主要依照所引教材目录；少数民族新闻传播、跨国华文传播及台港澳不同历史阶段尚未形成充分材料覆盖，后续另行补充。”不要为追求完整在本次补写无源事件。
2. 第 345 行“正在从单一通史叙述扩展到……”容易把整个史学发展概括为单一、线性的替代过程。N-CN-06 摘要可支持作者提出或概括若干书写转向，不足以排除早期方法多样性。改为“蔡斐（2018）概括了媒介生态史、口述史、城市史等书写路径；本节点将它们作为通史之外的入门方向”。
3. 第 353 行关于各种框架遮蔽作用的概括，应明确为 N-CN-07/N-CN-08 所代表的史学反思，不作为所有研究者接受的共同评价。方法差异本身不等于已证实的“争议”；`contested` 可保留，但需让学生能找到具体被批评的框架和相应作者。
4. “中国新闻史”“中国新闻事业史”与更宽的“中国新闻传播史”不宜无条件当作完全同义别名。保留 `common_name` 时在 alias 的 `note` 明示传统课程名、范围未必完全相同。

### 关系、定位与时效

- 与学科化节点的对称边只保留一次。与马克思主义新闻观节点的对照可标 **interpretive**，明确比较“历史重建与规范/理论组织两种节点任务”，不暗示二者学术对立，也不暗示史学不存在解释立场。
- C15 目录 locator 足以支持范围主张；不够支持各时期具体史实。N-CN-04 为可访问 98—104 页访谈，最好把“有关……问答”替换成准确页码加问题首句。
- “正在”及当下范式判断应改成带年份的作者观点，否则需动态复核。即使保留 `relatively_stable`，完整节点仍必填 `last_evidence_check`。

## 4. 方汉奇

### 可保留

- 未用“唯一奠基人”“最高水平”等无条件称号，也未制造“方汉奇理论”。
- 履历、作品、方法主张与独立评价分成四项；自述《通史》是阶段性集体成果的边界清楚。
- N-CN-05 与 N-CN-09 提供校方人物材料以外的研究线索，明显优于只援引荣誉材料；但来源的独立性和证明力度仍需分开判断。

### 必修项

1. **未逐项列证的身份字段。** “方汉迁”曾用名、首批荣誉教授、首批荣誉一级教授、创会会长写在 `aliases`/`roles`，目前正文证据对象主要对应任教经历和著述，未逐项定位到这些具体称谓。不得由 C20 泛称“学术职务”推断每一精细头衔。最小修订是先删减为现有定位支持的“新闻史学者、教育者、新闻史研究组织者”，或把每项称谓列为 claim 并补 C20 的准确段落；当前不能确认者标 **pending**。
2. 摘要“长期任教于北京大学和中国人民大学”模糊了两段长度。依据草案自身已有 1953、1958 年节点，改为“曾在北京大学任教，后长期从事中国人民大学新闻史教学研究”，不必追加未经核验的当前在职判断。
3. C20 是 2017 年机构材料，适于当时履历；`roles` 中使用无时间的“教授”等称谓容易呈现为现时职务。用“据2017年校方资料……”或历史任职表述，不据本次阅读补写任何现时个人状态。
4. 第 496 行由本人“重视史料/个案”的方法主张推到“构成学术影响的重要部分”是综合判断，应拆开。本人方法陈述可报告为 **direct**；影响评价只能限定为相应研究关注的维度，或标 **interpretive**。
5. N-CN-05 目前只有书目与简介，N-CN-09 为综述片段。它们可直接支持“存在以方汉奇影响力为对象的研究”和“这些研究讨论的范围”，不足以让编辑自行确定影响强度、独立性或所有具体结论。两个来源可能都围绕同一本专著，不能当作两次独立实证验证。正文“从独立研究而非纪念性材料……”建议改为“了解一部专门讨论其学人与学科关系的研究”。

### 关系、定位与时效

- `p-fang → associated_with → r5-marxist-journalism`：端点类型合规，但**hold**。本人主张历史唯物主义，不足以自动证明与这个更具体的新闻观传统形成怎样的学术关联。方法立场不等于特定传统成员或思想归属；`interpretive` 标签不能补足缺失的桥梁证据。保留于人物方法主张即可。
- `r5-china-history → builds_on → p-fang`：词表形式上允许节点到节点，但语义过宽。来源讨论具体作品、编纂与组织贡献，边却称整个课程与研究骨架承接一个人。**hold**；优先保留人物与领域的学习推荐。不要改成 `developed`，该词在本体中只允许人物指向理论/模型/概念。
- `none_identified` 的解释已避免“没有争议”误读；建议不只限定于“身份争议”，明确表示本轮未发现需新增到人物卡的已定位争议，具体史学判断仍依相关节点审查。
- 补 `last_evidence_check`；访谈已有页码范围，应补单项 claim 的准确页码，不能一律用“后半部分”。

## 5. 公共关系与战略传播

### 可保留

- 正文与证据注释已明确公共关系、战略传播不能简单等同；职业守则不是法律，也不是实际遵守程度的经验结论。
- N-PR-03 的原始学术定义、N-PR-05 的综述摘要与 G10 的课程样本共同提供不同层次入口，**没有仅依靠职业协会定义整个并列领域**。

### 必修项

1. 第 626 行应直接写“PRSA 将公共关系界定为……”。目前“非唯一学术定义”只在证据说明和局限中，首屏仍容易读成无来源归属的唯一正式定义。引用职业定义可以保留，不必为修正此处立即扩张文献。
2. 第 634 行“战略传播在研究中通常指……”以一篇 2007 年论文为主，不能自动代表当下学界通常用法。改为“Hallahan 等人（2007）提出的一种定义是……”。摘要“更宽的跨专业框架”也应限定到所采用的入门框架，并保留 2026 年综述所述概念分歧；不得将“宽于公共关系”展示成无争议的固定学科层级。
3. 第 650 行“公共关系伦理至少要求……”范围过于普遍。改为“所引 IPRA、PRSA 职业守则要求……”，标明组织、版本和对象。守则能证明规则被倡议，不能证明风险实际发生的频率、职业界普遍共识或制度执行效果。
4. “组织目标与公共利益可能发生张力”的提示可作为 **interpretive** 伦理问题；支持注释“守则之所以要求……正表明……”属于编辑推断，不得补成实证事实。需给学生清楚提示：此处是在提出需要检查的问题。
5. G10 现有登记是 2026 年 Public Relations 页面；草案 locator 与阅读标题写成“Public Relations / Strategic Communication”。应保持已核页面题名，另一称名是否出现在同页属于待核，不能因本节点并列命名而改写课程标题。
6. “组织战略传播”是被草案自己标为较窄相关词的条目，不是严格别名；建议从 aliases 删除并留在边界说明。

### 关系、定位与时效

- `r5-public-opinion → applied_to → r5-pr` 形式上为概念到应用，合规；但边正文实为“公共舆论分析”这一研究活动。PRSA 职责列表支持分析公众意见，未直接支持公共舆论概念的特定理论应用。本体要求具体应用证据，当前建议 **hold** 或改为学习推荐；不能为了词表匹配把概念悄悄改成方法。
- `r8-quant → used_in → r5-pr` 和 `r8-qual → used_in → r5-pr` 的方法到应用端点合规，但 N-PR-06 是行业测量评估规范，仅能证明该框架倡议结合定量、定性分析。它不直接证明规范化候选表中“量化研究设计与统计推断”或“质化研究设计与解释”整个方法簇的具体适用方式；关系正文还新增了关系质量、情境、目标设定等组合判断。两边目前 **hold**，不保留 `direct`。最小修订是把 Barcelona Principles 作为带版本的学习资源或规范性 claim，待实际方法文献/研究补齐后再连边。
- N-PR-04 的“Social Media as a Reflection of Majority Opinion”应定位到实际伦理意见页面/稳定段落；当前只有通用 Ethics 页地址，不能确认该标题与内容实际位于所引 URL。此条具体定位 **待核**。
- N-PR-06 第二条边 locator 仅写“关于……的原则”，应补准确原则号及 PDF 页码。第一条“原则1—7”过宽，按子命题拆分定位。
- 相对稳定的应用领域可保留 `relatively_stable`，但缺 `last_evidence_check`。凡使用 2026 年课程、2025 年行业规范和“最新”字样，应在可见材料中标版本并安排 `as_of`、`next_review_due`；最小修改是用“2025年4.0版”代替“最新”。

## 共通 Schema 不一致与最小修订

这是依据 Schema 的人工逐字段核对，未宣称完成解析器运行验收。当前 Markdown/YAML 草案不是可直接投喂三个独立 Schema 的最终记录。

| 草案结构 | 与现有 Schema 的不一致 | 最小修订 |
|---|---|---|
| 五节点 `name_en` | node 顶层 `additionalProperties: false`，不允许该字段 | 英文原名的节点用 `name_original`；中文原生名称的英文译名可用合法 alias 与 note 保留，或由主代理明确修订本体后统一添加字段 |
| 五节点 `candidate_relations` | node 不允许嵌套此字段；关系有独立 Schema | 拆成独立关系记录，不为方便导入放宽所有额外字段 |
| 20 条 `key_points` 的 `claim_kind` | claim 不允许 `claim_kind`，且全部缺必填 `evidence_status` | 逐项判断 `direct/interpretive/pending`；“规范/历史综合/经验事实”不能机械映射为证据状态。当前 Schema 下在 statement 或 support_note 显式保留类型标签；若要独立字段须先协调规范变更 |
| 所有 `limits_or_debates` | claim 缺 `id`、`evidence_status`；其证据普遍缺 `support_role` | 生成稳定 claim ID，逐项判断状态并补合法角色 |
| 新闻观 `internal_differences` | Schema 要求 claim 对象数组，草案为字符串数组 | 转为带 ID、statement、状态、证据的 claim；无来源的编辑分层勿伪装为直接证据 |

| 全部 learning_links 的 `order/rationale` | 不允许这两字段，缺必填 `reason` | rationale 改 reason；明确前学/后学/比较的用 sequence_hint，数组顺序不能等同于 before/after 含义 |
| 别名 kind | former_editorial_title、descriptive_alias、related_broader_term、overlapping_term、common_short_name、historically_common_name、romanization、narrower_related_term 都不是合法值 | 不可盲目全改 common_name：相关上位词/下位词移入边界说明；旧编辑标题删除或记版本日志；真正俗称用 common_name，音译/转写用合法名称类别加 note 或统一扩展枚举 |
| 后四节点无 last_evidence_check | complete 条件要求此字段 | 由实际核验者填写日期；不能由审查日期推定已重查外部证据 |
| 关系的 source/target/statement/status | Schema 需要 source_id/target_id/statement_zh/review_status，且没有 status:candidate | 逐项重命名；候选阶段用 review_status:draft；补 reviewed_at:null，不能把本次“hold”填作 Schema 状态 |
| 关系 evidence | 全部缺 support_role | 按实际支持方向逐项补值；scope_note 虽非 Schema 必填，但上述限定关系均应填写 |
| 对称边双向重复 | Schema 单条能通过，不会发现跨记录语义重复 | 对 `contrasts_with` 的无序端点对去重，只保存一个方向 |
| 15 个临时来源 N-CN-01—09 / N-PR-01—06 | 不满足 source `id` 的 `^[A-Z][0-9]{2,}$`；正文标题也未等同显式 id 字段；尚未进入两个正式登记表 | 由主代理集中分配不冲突 ID、建立映射并同步所有引用；不要各代理独立占号 |
| 临时来源 authors_or_organization | 草案是标量字符串；Schema 要求非空字符串数组 | 按真实作者边界拆分数组，保留口述/访问等贡献角色说明 |
| 临时来源 language: zh | Schema 只允许 zh-CN/zh-TW 等 | 按实际文本语言/字形选择合法值，不按作者所在地自动转换 |
| 临时来源 access_status | abstract_and_metadata、abstract_and_references、catalog_metadata_and_description、full_text_web_reprint、metadata_and_review_excerpt、full_text_pdf 等都不合法 | 按实际取得材料映射 abstract/metadata/full_text/unavailable；转载、PDF、只核片段等细节保留 bibliographic_note，尤其不能把 review_excerpt 自动映射全文 |

另需统一短名单末段的 `needs_review`：它不在本体或 Schema 的审核枚举中。按实际阶段用 `ready_for_review` 或 `needs_revision`，不要新增未经约定的拼写。

## 最小修订与复审顺序

1. 先保留三层区分，将所有主张补成 Schema 合法记录；来源归属、年代和范围进入学生可见 statement，不能只保留在机器不展示的注释中。
2. 收窄 1982 年会名、当前教学体系、史学线性转向与统一战略传播定义；补中国新闻史覆盖缺口说明，删除或待核精细人物称谓。
3. 暂不合并本报告明确 hold 的关系；其教学价值可由学习链接承载。去除两条逆向重复边中的一条。
4. 主代理集中将 15 项临时来源入库并同步引用，检查已有登记中的访问限制。摘要可以支持摘要明确表达的主张；书目简介不能替代全书论证；机构网页不自动决定学术争议。
5. 补关键 locator、完成实际核验日期与动态材料版本；再做 Schema、端点类型、引用存在性、对称关系去重和逐主张复审。只有来源字段合法而主张仍越界，不能判 pass。
