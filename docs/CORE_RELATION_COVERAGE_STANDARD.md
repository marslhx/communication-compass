# 八区核心入口：最小关系覆盖标准

**版本：** 2026-09-15
**适用范围：** 八个首页问题区域的 starter 入口节点。本文规定的是关系的证据与展示门槛，不是节点完整度、关系总量或前端默认可见数量的指标。

## 1. 目标与非目标

核心入口需要让学生从一个概念进入一条可追溯的学术脉络或可操作的学习路线；它不需要成为一个“边数相同”的小型图谱。一个覆盖多种理论、传统或方法的伞形入口，可能在当前证据下只有一条合格的学术关系。该情况应保留并说明，不能以相邻概念、共同分区、关键词相似或教学便利补成 direct 边。

本标准不把下列内容计入 direct 覆盖：共同属于某一区域、页面的学习链接、课程并列、从法规推出实际效果、从人物名望推出理论归属，以及由复合端点的一部分证据归属整个端点。

## 2. 三层关系必须分开

| 层 | 可以回答的问题 | 入图条件 | 是否计入最小覆盖 |
|---|---|---|---|
| **direct 学术关系** | 谁提出／发展了什么？某理论实际研究何对象？某方法在哪个具体研究中被使用？ | 端点、关系动词和范围均能由可定位原典、学术研究或等价权威记录直接支持；`evidence_status=direct` 且关系已复核 | 是 |
| **interpretive 教学比较** | 两个节点分别在问什么、可如何比较或互相限定？ | 两侧材料足以支撑比较，但“二者的关系”本身是编辑组织；必须标为 `interpretive`，写出比较维度与范围 | 否 |
| **learning path 学习路径** | 先读什么、再学什么、应在哪一步停下来检验？ | 有明确的教学理由、顺序提示和端点边界；不要求证明思想谱系 | 否；不得自动转为学术边 |

同一对节点可以同时有 direct 关系和学习路径，但前者不能只因后者存在而推定。`interpretive` 也不因已有来源 ID 而升级为 direct：来源必须直接说到该两端之间的关系，而非只支持其中一端。

## 3. 起点的最小覆盖门槛

每个 starter 入口的最低要求是：

1. 至少 **1 条**与该节点相连、已复核的 `direct` 学术关系；可为入边或出边。
2. 该边必须是**非冗余锚点**：人物—理论／模型的提出、传统—对象的明确研究、方法—具体研究场景等。不能只重复节点正文中的泛泛定义。
3. 每条计数边应至少显示一个来源 ID、可定位 locator、关系动词和范围限定；一篇共同署名原典可以支撑两位作者各自的贡献边，但不得把两个作者压成一条“集体作者”边。
4. 若未找到合格边，正确状态是 `0 / 最低 1，证据缺口`；可显示学习路径或解释性比较，但不以它们补足该数字。

**建议的成长目标（非发布门槛）：** 先补到 2 条彼此不重复的 direct 锚点，例如“人物／原典脉络 + 具体研究对象或应用”。只有第二条能以独立且精确来源闭环时才添加。三条以上不构成更高质量的自动证明。

## 4. 计数规则

- 计数单位是**关系记录**，不是来源、主张、学习链接或页面同现次数。
- 对本标准而言，“当前 direct 数量”只统计 `content/data/relations.json` 中与 starter 相接、`evidence_status=direct`、`review_status=reviewed` 的记录；入边和出边均计入。
- `pending`、`ready_for_review`、`interpretive` 一律不计数。节点本身仍可处于 `ready_for_review`；关系合格不等于整节点已发布。
- 对复合端点，证据只支持其中一部分时不计数。例如香农的工程模型可支持“噪声”，不能自动把“反馈与噪声”整个复合节点归为其发展成果。
- 同一原典支持的多条边，只有各边的端点与动词均被原典直接支持时才可分别计数；否则保留一条较窄的关系或降为解释层。

## 5. 关系动词与范围检查

优先使用可证实的窄动词：`proposed`、`developed`、`associated_with`、`addresses`、`used_in`。下列审查问题须全部能回答：

1. 来源明确说的是哪两个端点，而不是只涉及相近主题吗？
2. 动词是否比来源结论更强？例如法规能支持“规定义务”，不能支持“治理已奏效”。
3. 关系范围是否被锁定在原研究、特定法域、特定案例或材料类型？
4. 是否把传统、人物、理论或方法的不同层次混成单一结论？

无法通过时的处置顺序是：缩窄端点或动词 → 标为 interpretive → 改为 learning path → 明确留空。不得为了达到第二条或第三条关系而跳过这一顺序。

## 6. 展示与维护

- 默认学术图只可选用已复核的 direct 边；解释层须可独立开关并标明“本站整理的比较”。
- 学习路径在节点卡和导览中展示，不进入关系计数或默认事实层。
- 每次新增 starter direct 边，都要在关系审计中记录：来源 ID、locator、支持的精确命题、未支持的外推，以及是否改变本入口的覆盖状态。
- 每次改变复合节点、关系类型或来源访问范围，都要重算八区计数；不以历史数量沿用为依据。

## 7. 当前审计的解释

2026-09-15 审计表明八个 starter 都达到 `1` 的最低锚点，其中议程设置有三条、其余多数只有一条。该不均衡是当前证据结构的结果，不是待用“关系密度”修复的缺陷。逐项候选、可用来源与明确缺口见 `research/p1-core-relation-gap-audit-2026-09-15.md`。
