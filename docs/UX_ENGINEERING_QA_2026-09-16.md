# 界面、反馈与工程优化验收（2026-09-16）

## 本批范围

本批对应执行顺序中的步骤 4、6、7，不扩展学术内容范围：

- 页面视觉与信息结构闭环；
- “关于本站”、反馈与发布说明；
- 工程分包、可访问性、图片性能与跨端验收。

## 已完成

1. “关于本站”重排为项目定位、开放校订、整理流程、两类连接、状态说明、当前不足、作者/版权/隐私。证据标签的详细解释改为折叠内容。
2. 新增 `/feedback`：区分内容纠错、使用体验和内容建议；可复制或下载 Markdown 反馈单；草稿仅存在当前浏览器。
3. 每个知识点增加“反馈这个知识点”，自动带入知识点名称和页面路径。
4. 学科图谱的全量布局由两环扩展为自适应两/三环，27 个知识点可在当前范围同时呈现，手机端仍保留完整列表。
5. 关系图去掉与页面背景交叠的装饰环/曲线，关联圆点继续直接跳转相应知识点。
6. 浅色主题增加独立的知识类型文字色和焦点色；补齐 `:focus-visible`、键盘页签、减少动效偏好和非 `color-mix` 回退。
7. 知识点、关系和关于/反馈页改为路由按需加载。证据数据独立为约 60.45 kB gzip 的延迟分包；入口 JS 由约 295.35 kB gzip 降至 236.19 kB gzip。
8. 麦库姆斯与格伯纳的本地肖像转为 WebP，合计由约 1 MB 降至约 44 kB；知识点页图片已使用延迟解码。

## 验证结果

- `npm run typecheck`：通过。
- `npm run lint`：通过。
- `npm test -- --run`：4 个测试文件、21 项测试通过，包括知识点深链接、反馈页预填与关系跳转。
- `npm run content:check`：131 个知识点、46 条关系、264 条来源通过。
- `npm run build`：通过，生成独立的知识点、关系、关于/反馈和证据数据分包。
- Chrome 真实浏览器检查：关于页、反馈页、浅色主题、27 知识点图谱和议程设置关系图正常；控制台无 error/warning。
