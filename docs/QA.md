最终执行：

```bash
python3 scripts/normalize_research_data.py
python3 scripts/assemble_content.py
python3 scripts/validate_content.py
npm run typecheck
npm run lint
npm test
npm run build
npm audit --audit-level=moderate
```

## 内容与关系闸门

- 15 个完整样本中，9 个通过独立节点复核；其余 6 个因合计 10 条 pending 主张保持降级状态。
- 22 条编辑关系中，10 条 direct 和 11 条 interpretive 进入各自公开层；1 条 pending 只留在编辑数据，不进入公共 JSON 或生产包。
- 关系白名单同时锁定 ID 与批准层级；interpretive 关系改成 direct 会被装配器／校验器拒绝。
- 公开关系记录必须与内部已复核记录逐条完全相同，防止生成副本发生静默漂移。
