# COMMPASS｜传播学指南针首版完善执行计划

> 建立日期：2026-09-14  
> 目标：把当前“可用的内部测试版”推进为“可供学生试用、可在 GitHub Pages 预览、内容状态诚实可解释”的首版候选。

## 执行原则

- 前台保持低密度、渐进披露，不以节点总数作为完成标准。
- 内容状态区分“资料整理中”“开放校订”“已完成基础校核”，不使用“骨架条目”“完整样本”或容易被理解为同行评审的笼统“已审核”。
- 有出处的学术关系与本站教学整理的比较分开展示。
- 内容扩充先依据课程覆盖矩阵确定优先级，再逐项调研、引证和基础校核；争议性、高风险条目再安排独立专家复核。
- 每个阶段必须通过自动校验和人工关键路径检查后才能关闭。
