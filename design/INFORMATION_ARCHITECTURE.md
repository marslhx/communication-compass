# COMMPASS｜传播罗盘：真实内容信息架构

日期：2026-09-11。状态：内容闸门通过后的信息架构决策，供低保真、高保真和前端实现共同使用。本文件不新增知识节点、学术事实或关系。

## 0. 视觉复核后的交互覆盖规则

2026-09-11 第二轮界面复核确立以下规则；如与本文后续旧描述冲突，以本节为准：

- 全站区域、范围、类型、状态和关系视角使用可见的分段按钮，不使用下拉菜单。
- 学科图谱使用稳定的“左侧八区／中心轨道／右侧聚焦”构图，不提供方向移动、缩放或拖拽按钮；移动端直接给同内容列表。
- 主题导览卡只显示与首页一致的 `short_title` 和编号，整张卡片可点击，不另设“进入”文字链接，也不在卡片内堆叠介绍与计数。
- 节点页固定为“概览／起源与人物／核心命题／争议与边界／延伸学习”五个章节标签；一次只展示当前章节，避免长页面连续堆叠。
- 节点涉及的主题只作为彩色位置徽章呈现，不作为跳转链接；返回与跨页定位由面包屑、主题目录和关系坐标承担。
- 列表卡整卡可点击，保持类型连续分组；卡内只保留名称、原文名、类型与内容状态。

## 1. 产品骨架与 A 方案的落地

首页采用 `layout-a-compass.png` 的深色空间、八区圆盘、稳定方位和右侧聚焦卡。节点详情采用 `detail-v1-reading-first.png` 的阅读主次关系；`detail-v2-relations-first.png` 的中心节点与证据面板只用于独立“关系探索”模式。三张图已逐张查看。

三图是构图参考，内容以 content/data 和 STATUS_RULES 为准：八区使用 areas.json 的八个真实问题；议程设置的主区为“信息如何影响个人与群体”；来源于示意图的“相邻”“影响”、人物肖像、引语和时间轴不作为学术数据。现有节点没有统一的起源年代字段，首版不把来源年份或更新时间推算为节点年代，也不实现示意图的全局历史滑杆。

统一的三条主入口是“学科图谱”“主题导览”“搜索”。人物、理论、方法和前沿是目录/搜索筛选器，不再占据与三入口同等权重的一级导航。深色背景上的方位、刻度与微弱纹理承担空间识别；不得以地理轮廓暗示知识来自某地，不用节点大小或边数代表学术重要性。

当前真实数据为 8 区、80 个入口（65 个骨架条目、15 个完整样本）：9 个完整节点已复核，6 个完整节点因含待核主张保持待审核。22 条关系中，10 条 direct 关系已复核并进入默认学术图层，11 条 interpretive 关系已复核并进入默认关闭的编辑比较层，1 条 pending 关系不公开。空间导航、阅读和学习推荐仍须在任一节点零边时完整可用。

## 2. 路由及可恢复状态

路由使用 node.slug，不从中文标题生成；内部引用使用稳定 node.id，再查出 slug。允许直接打开、刷新和浏览器前进/后退。

| 路由 | 页面职责 | URL 中保留的状态 |
|---|---|---|
| `/` | 八区罗盘首页，也是学科图谱的全景层 | 无默认选择；`?area=effects` 可定位区域预览 |
| `/map?area=effects` | 桌面区域空间探索；手机提供同一区域列表 | area、可选 focus=node.id、layer=academic/comparison；缺省 academic |
| `/guides` | 八个问题主题及两条由已有 learning_links 组成的入门路径 | 可选 area 筛选 |
| `/areas/:areaId` | 一个问题区域的阅读型目录 | type、level=candidate/complete、scope=primary/all；缺省 primary |
| `/nodes/:slug` | 阅读优先知识页，骨架条目也有有效页面 | 可选 fromArea；hash 定位 `#key-points`、`#evidence`、`#pending` 等 |
| `/nodes/:slug/relations` | 独立关系探索 | layer=academic/comparison；可选 relation=关系ID；fromArea |
| `/search?q=…` | 搜索结果与组合筛选 | q、area、type、level；缺省不排除骨架条目 |
| `/guides/process-to-reception` | 传播过程到受众研究的学习顺序 | step=node.id；缺省第一站 |
| `/guides/journalism-history` | 新闻观、新闻史与人物的学习顺序 | step=node.id；缺省第一站 |
| `/about` | 如何使用、八区是编辑导航、状态解释、内容范围 | hash 可定位 `#evidence-status` |

来源和单条主张证据采用就地展开，使用可复制的 `#claim-主张ID` 或 `#source-来源ID` 锚点，不再建立空洞的独立“来源首页”。关系详情放在关系模式的右侧面板/手机下方区块，URL 中可恢复选中的 relation。

来源不明的返回入口一律回当前节点主区。由搜索进入时，浏览器返回恢复原查询、筛选及滚动位置；由导览进入时恢复步骤。fromArea 只影响“返回刚才的区域”，不覆盖节点唯一主区。非法参数忽略并提示已回到有效视图；未知 area/node/guide 显示明确的未找到页面，提供搜索和八区入口。

## 3. 首页：先认八个问题，再选择入口

桌面首屏依次包含：品牌与三入口、简短任务句“从一个问题，找到传播学的位置”、中央八区罗盘、右侧引导面板。页脚或首屏下缘明确“八个问题是本站的教学导航，可交叉探索”。首次不自动选中某个理论，不默认展示全部节点。

罗盘八块使用 areas.number 固定顺序、areas.color 固定配色和 short_title。圆盘文字保持水平；完整 title/question 出现在旁边说明中，不沿弧排长中文。中心显示“从一个问题开始”，只作说明，不模拟可交互指针。

| 区域 | 默认阅读入口（主区内） |
|---|---|
| communication | r1-process：传播过程与基本要素 |
| meaning | r2-encoding-decoding：编码与解码 |
| media_society | r3-medium-theory：媒介理论 |
| effects | r4-agenda-setting：议程设置 |
| institutions | r5-gatekeeping：把关理论 |
| power_culture | r6-decolonial：后殖民与去殖民传播 |
| digital_ai | r7-platform-governance：平台治理 |
| research_application | r8-content-analysis：内容分析 |

这是教学起点配置，不是重要性排名。点击/键盘激活区域后，右侧面板显示区域完整问题、intro、当前范围内的入口数、上述一个起点的名称/类型/成熟度，以及“阅读这个起点”“浏览本区目录”“在图谱中展开”三个操作。面板不塞完整知识正文。另提供最多两个同区完整样本供继续选择；若没有，保留一个起点，不从他区填满位置。

hover 只提示可点击，不改变已选区域，不触发自动跳页。点击起点才进入知识页。首页下方展开八区的文本目录和“按学习顺序开始”路径卡，保证不理解罗盘的人也能完成同样任务。

## 4. 学科图谱：分层空间导航

全景层只显示八区；区域层只展开一个区域，默认最多 8 个条目，其余显示“查看本区其余入口”并进入可展开的区域目录。先展示配置起点、其余完整样本，再按主数据顺序显示骨架条目；不按度数、随机力模拟或未经论证的重要性排序。

当前区域默认是主区归属，切换“含跨区条目”后按 id 去重。跨区条目带“主区：…”标签；区域归属采用淡底分区和文字标签表达，不画成学术关系。节点位置只是教学布局，距离没有理论接近程度含义。

桌面提供缩放、平移、重置、区域切换、图层切换及“同内容列表”。选中一个节点时只显示名称、类型、状态、主/次区和“阅读”“探索关系”；按需转到独立关系模式。列表与空间图使用同一过滤结果，图中不可见的条目必须可在列表找到。

手机 `/map` 默认呈现八区切换和节点列表，保留“当前区域”提示，提供轻量静态罗盘定位。手机无需拖拽或缩放即可发现、阅读全部 80 入口。桌面可探索全部数据，但“完整图谱”不等于在第一屏绘制 80 个节点。

## 5. 主题导览与区域目录

`/guides` 先给八个真实问题卡，再给两条入门路径。主题卡显示 question、intro、入口数和完整样本数；不能用八张空泛宣传卡替代具体节点。进入 `/areas/:areaId` 后显示区域问题、范围说明、起点、筛选及条目列表。

默认 primary 范围说明为“以这里为主要入口”；all 范围说明为“也从这个问题进入”。结果计数按当前范围和筛选计算，不把跨区重复出现累计为更多知识。每项显示中文名、原文名、类型、成熟度、其他归属；骨架条目可展开入选说明和来源线索。列表默认不截取待核主张作为卖点。

筛选轴是节点类型、完整度、区域。将“含待核”作为明确的内容状态提示，可附独立筛选；`temporal_profile=evolving` 只能称“持续更新条目”，不能直接等同“前沿”——如中国学科史也标 evolving。“前沿议题”预设使用 subtype=frontier，名称与过滤条件公开对应。

两条首版路径只利用现有 after 学习链接：

| 路径 | 节点顺序 | 边界 |
|---|---|---|
| 从传播过程到受众研究 | r1-process → r2-encoding-decoding → r4-audience | 最后一站是骨架条目，入口卡预先提示这一点 |
| 从新闻观进入新闻史 | r5-marxist-journalism → r5-china-history → p-fang | 方汉奇返回新闻史的链接不自动追加到路径，避免循环 |

路径页将每一跳的现有 learning_links.reason 呈现为“为什么接着看”，显示每站成熟度，允许直接跳到任何一步。路径步骤是教学顺序，不是思想承继或历史因果。路径条不能混入学术图层；不因完成浏览而声称学生已经掌握内容。路径读到最后显示“已到这条导览的最后一站”，并回到该节点现有的学习推荐。

## 6. 搜索：无需先知道学科位置

所有页面的搜索入口可见。搜索表单有明确标签“搜索理论、人物、概念或问题”，Enter 提交至 `/search`。输入、结果和筛选状态不依赖悬浮命令面板；可提供 `/` 聚焦快捷键，但文本输入中不触发。

索引字段：name_zh、name_original、aliases.name、type、区域 title/question；完整节点还可索引 direct 与 interpretive 主张。pending 主张、来源 support_note 中的待核内容、未选中的草案不入公开搜索正文索引。中文空格/全半角和拉丁大小写做检索规范化；不自动用生成式同义词扩张学术概念。

排序固定为主名精确匹配、主名/别名匹配、原文名匹配、其他字段匹配，同分保留主数据顺序；不因骨架条目未完整而藏掉精确命中。结果显示完整名称、匹配别名及其 note、类型、状态、区域；默认无主张摘句。如提供正文命中摘要，展示完整的被命中主张及其证据状态，过长时“展开此段”，不能截掉范围限制后形成新的肯定结论。

示例：搜索“议题设置”命中议程设置，并显示“匹配别名：议题设置”；搜索“传播学去西方化”命中 r6-decolonial，同时保留不作严格同义词的限定；搜索“文化研究”仍进入骨架条目，不加载留存的完整草案。

## 7. 知识页：阅读优先，结构按类型展开

桌面正文约占主要阅读区的三分之二，侧栏放页面目录、区域位置和“探索关系”；正文行宽保持适于阅读。侧栏不放持续运动的小图。手机单栏，目录可折叠，正文按同样顺序排列。

| 顺序 | 区块 | 数据及展示规则 |
|---|---|---|
| 1 | 返回位置与页头 | H1=name_zh、name_original、类型、成熟度、主区和次区；标题完整换行 |
| 2 | 范围、版本与时效 | naming_boundary、必要的 summary 范围句、动态三日期/current_evidence_state；未填不编造 |
| 3 | 它是什么 | 完整展示 summary，不能截掉末尾限制；来源 ID 渲染为可展开文献引用，不把字段名直接展示给学生 |
| 4 | 为什么值得学 | why_it_matters |
| 5 | 核心要点 | key_points 中 direct/interpretive；每条紧邻证据标签与证据展开 |
| 6 | 这一类型怎样理解 | 按下表插入类型字段；其中所有 claim 数组继续遵守证据分层 |
| 7 | 局限与争议 | limits_or_debates、positions、controversy_note；争议状态与证据不足分开 |
| 8 | 待核与版本差异 | 六个 claim 集合里的 pending 集中在此，默认折叠并显示数量；打开后每条标“待核” |
| 9 | 学习材料与来源 | learning_resources 的 title/purpose/level/locator，加关联来源的作者、年份、URL、访问范围/日期；“全部引用来源”去重 |
| 10 | 下一步学习 | learning_links 按 before/after/compare 分组，保留 reason 和目标成熟度 |

类型模块：theory_model 展示 questions_explained、propositions、conditions；tradition 展示 central_questions、internal_differences、naming_boundary；person 展示 roles、communication_relevance，education_records 仅有经核数据才出现；method 展示 suitable_questions、data_requirements、typical_procedure、limitations；research_topic 展示 core_questions、current_evidence_state；concept/application 使用已有核心要点与边界，不造空的理论字段。

内容分析的资料要求和步骤须在模块顶部明示“编辑性练习安排”，并保留其方法细则待核边界。字段名 data_requirements、typical_procedure 不直接成为用户文案。含来源 ID 的既有摘要可将 ID 替换成可点击题名/短引文；除此之外不自动改写学术文本。

骨架条目使用同一路由和页头，但正文仅显示“该入口目前提供范围与学习线索”、candidate_note、归属和 source_leads。没有核心命题、经典研究、人物履历或推荐文章占位区。“华夏传播”额外显示候选证据待核及成熟度限定；“文化研究”不能因为有入边或来自霍尔的学习链接就显示为完整条目。

## 8. 独立关系探索

由知识页的“探索关系”进入 `/nodes/:slug/relations`。桌面左侧是当前节点及过滤/图层，中间是聚焦空间，右侧是选中关系的完整文字、范围说明和证据；顶部固定“返回阅读”。手机先给关系列表，选中关系在下面展开证据，图形作为辅助，不横向撑大页面。

默认只看一跳，不自动推断二跳/传递关系；有合格关系时最多先显示 6 条，再“查看全部”。正反方向用关系词表生成正确表达；contrasts_with 只显示一份。不能把 proposed 改成“影响”，不能把 associated_with 改成“创立”。每条线都必须能到达完整 statement_zh、scope_note、evidence，线色之外另有标签。

当前默认图层有 10 条已复核 direct 关系，编辑比较层有 11 条已复核 interpretive 关系。二者均只按当前聚焦节点展示一跳；某一节点在当前图层没有关系时，中心只显示当前节点，旁边明确“这里暂时没有可展示的已复核关系”，正文解释“关系需要单独核对；这不表示该条目与其他知识没有联系”。提供“返回阅读”“查看学习推荐”，后者转到知识页的学习链接区，不能把推荐连线伪装成学术边。无需显示内部待审核边的条数以制造看似有内容的图。

“证据透明／编辑比较”开关只显示已复核 interpretive 关系，使用独立线型、图例和“编辑归纳”标签。pending 关系不进入任何公开图层，也不提供“显示所有待核边”开关。对通过 URL 强行指定的未审核/不存在 relation，显示“这条关系暂不可展示”，不会绕过过滤器。

## 9. 数据选择与状态的统一实现约定

页面只读取 content/data 的装配结果；content/revised、drafts 和 complete-node-selection 不作为运行时补内容来源。统一构造 nodeById、nodeBySlug、sourceById、areaById；所有页面共享同一选择器，不能独立复制审核判断。

1. `allClaims(node)` 遍历 key_points、limits_or_debates、positions、propositions、limitations、internal_differences。`hasPending` 据此计算，不只看核心要点。
2. 成熟度文案严格取 STATUS_RULES：candidate→“骨架条目”；complete 含 pending→“完整样本 · 含待核”；complete 无 pending 且 ready_for_review→“完整样本 · 待审核”；reviewed/published 按既定标签且日期非空。状态不一致的记录不显示已核验，提示资料正在整理，并交由编辑处理。
3. 普通目录卡默认只显示名称/类型/状态/归属，不从 pending 生成短结论。预览中的 summary 必须全量保留限制且显示成熟度；没有经过人工确定的安全短摘要时，不自动摘要或只截第一句。
4. `academicRelations` 至少满足 reviewed/published、非空 reviewed_at、direct、端点存在和类型合规、有可展开证据；`comparisonRelations` 同样检查审核和端点但要求 interpretive。首版的 candidate 与 complete 都是可访问的公开条目，因此可作为已复核关系的端点，但端点必须同时显示自身真实成熟度，关系证据不得把 candidate 或含 pending 的 complete 升格。pending 永远排除。
5. `learningLinks` 单独读取，只检验目标存在和展示目标实际成熟度；不依据关系表猜“下一站”，不根据当前页面给目标升格。
6. 区域按主/全部归属选择后以 id 去重，单一主区保持稳定。跨区理由原样保留；候选记录泛化的“后续补充理由”不能被渲染成已证明的理论关系。
7. 来源访问范围严格使用 STATUS_RULES 文案，并同时说明“可读范围不代表主张已获支持”。direct→“来源直接支持”；interpretive→“编辑归纳”，其理由在当前阅读位置可见；pending→“待核”。
8. evolving 同时显示 as_of、last_evidence_check、next_review_due；空值显示“尚未记录”。超期显示“需要重查”，不自动失效。候选的机械日期不标作逐项学术复核完成；已有 null 不用 updated_at 补齐。
9. 运行断言以数据和 `complete-node-selection.json` 为准：总量保持 80 个唯一节点；complete 数量随证据补全逐步增长；candidate 为余数；pending 关系始终不进入公开图层。页面计数从数据计算，文案不硬编码为永久数字。

## 10. 状态与边界案例验收

| 场景 | 可见行为 | 必须避免 |
|---|---|---|
| 长标题：中国大陆再引进与学科化 | H1/列表标题自然换行，原文名另行，状态独立一行；面包屑末段可缩短但 H1 保留全名 | 固定高度裁字、让英文撑出手机宽度 |
| 多区：公共领域 | 主区保持 institutions，其他区域为可点击入口，归属理由可读 | 为每区复制知识节点，随入口改变主区 |
| 含待核：传播过程 | 页头含待核标签；pending 集中可展开；已支持部分仍可阅读 | 待核句进入首页结论，或把整个节点全部隐藏 |
| 动态：平台治理 | 三日期、法域/版本与 current_evidence_state 同时可见，欧盟版本缺口保留 | 一个“更新至今日”替代不同核查范围 |
| 骨架：文化研究、华夏传播 | 前者明确骨架，后者另示候选待核，来源线索可用 | 读取留存完整草案、从来访链接赋予成熟度 |
| 版本：编码与解码 | 1973 年四分稿和后来三分框架的限制同屏可读 | 把版本限定截掉或自动合并 |
| 命名：媒介理论、后殖民与去殖民传播 | 原文名/命名边界可见，别名 note 保留 | 将英文含义不同的术语视作无条件同义词 |
| 当前节点在所选图层为 0 边 | 明确空状态、返回阅读/学习推荐可用，图层切换也守规则 | 假边、随机边、教学路径混入学术图 |
| 搜索无结果 | 显示查询和当前筛选，“清除筛选”“回到八区”；保留输入 | 自动编造新节点或强推不匹配理论 |
| 筛选清空区域 | 显示“当前筛选没有条目”，一键清除 | 把空结果当成区域没有研究 |
| 无学习链接/阅读材料 | 相应位置提示“尚未整理”，回区域目录 | 空白卡占位或生成推荐 |
| 数据读取失败 | 明确错误与重试；保留三入口和返回，不显示虚假 0 节点 | 将失败装成真实内容空集 |
| 外部来源不可访问 | 保留来源身份、定位和访问记录，显示当前不可访问状态（如已有） | 删除来源，或把打开链接等同于重新验证 |

## 11. 关键用户任务

新生从首页点“信息如何影响个人与群体”，读出完整问题并打开议程设置；能够从“为什么值得学”和研究边界知道这个入口回答什么。无需先理解图的拖拽和缩放。

知道术语的学生直接搜“议题设置”，辨认别名后进入同一议程设置页；打开某一主张证据，找到来源、定位、支持范围，再返回原结果。键盘与手机均可完成。

学生沿“从传播过程到受众研究”逐站阅读，看到每步推荐理由；进入最后的受众研究时认识到其仍是骨架条目，不误以为前面的完整样本赋予它同等证据成熟度。

学生从平台治理判断一条论述是学术定义、法规义务还是实际效果；能看到法域、文本版本与时效边界。无需先展开每一项来源才发现适用限制。

学生从知识页进入关系探索，能够区分默认学术关系与默认关闭的编辑比较关系；面对当前节点 0 条可用边时仍知道如何返回阅读或学习推荐，不会把“暂无已复核关系”理解为“这项知识没有关系”。

## 12. 键盘、无障碍与响应布局

所有页面使用 header/nav/main/aside/footer 和连续标题层级，中文主内容设 zh-CN；提供“跳到正文”。三入口使用真实链接，按钮只执行选择/展开，不能用不可聚焦 div 模拟操作。焦点轮廓在深色底上清楚可见。

八区罗盘使用可聚焦按钮或链接，按编号 01—08 的 DOM 顺序可 Tab 遍历，名称包含完整区域问题。Enter/Space 激活选择；不依赖颜色、方位或 hover。视觉罗盘和文本目录避免制造两套重复朗读内容：保留一套主要可访问控件，装饰路径和刻度对辅助技术隐藏。

地图必须提供同结果列表、可键盘操作的缩放/重置，不能设拖拽为唯一入口；区域/节点聚焦后给出明确名称。焦点更新不由 hover 触发。关系列表提供线条无法表达的完整方向、类型、范围与证据，因此 canvas/SVG 不是唯一信息通道。

路由切换后将焦点放到新页 H1 并更新文档标题；区域预览变化只适度播报选择结果，不抢夺焦点。搜索提交和筛选结果数用非打断式状态提示，输入过程中不逐键朗读全部结果。折叠区用原生 details/summary 或有 aria-expanded/aria-controls 的按钮；关闭证据面板返回触发位置。模态窗口如使用需 Escape 关闭、焦点约束与恢复，移动端优先内联证据避免层叠弹窗。

正文普通文字以至少 4.5:1 对比度作为设计验收目标，控件和焦点可识别；颜色之外同时有文本/形状说明。互动目标以至少 44×44 CSS 像素作为布局目标。200% 缩放、320 CSS 像素宽度下正文不横向滚动；极长 URL/英文名允许断行，证据标签不能挤出正文。文本不烘焙成图片。

桌面宽屏保留侧边导航、中心阅读/图谱、辅助面板；中等宽度辅助面板下移；手机顶部精简品牌和搜索，三入口保持文字可见，单栏阅读/列表替代复杂空间操作。手机不删去状态、证据、时效和学习推荐。动效只用于区域聚焦和短过渡，尊重 reduced-motion，关闭持续旋转、自动游走和视差。

## 13. 进入高保真和开发前的 IA 验收点

用上述真实节点逐一检查：首页一眼能认出八个问题和三入口；两个完整的阅读/证据任务无需任何拖拽；候选、含待核与已复核节点在首个视口就有正确状态；方法与传统的类型字段有稳定位置；手机可抵达全部内容；返回/刷新保留合理上下文；关系图层语义清楚且零边关系页不成为死路。高保真仅调整视觉、密度与节奏，不能用图示中的虚构文案、关系或年代替代已确定数据规则。
